## Folder Structure

The workspace contains two folders by default, where:

- `src`: the folder to maintain sources
- `lib`: the folder to maintain documentation related to my project (UML diagram, etc)

Meanwhile, the compiled output files will be generated in the 'bin' folder by default.

>If you want to customize the folder structure, open '. vscode/setting.json' and update the related settings there.

## How to use: Press the button which is displayed on the right top side, and it will display 4 butten, if you want to get the Random Fortune, press "Random", and if you want to add fortune, please write the sentence for the long and slender box, and press "Add Fortune". If you want to remove fortune, press "Show all," and you can see all articles, so you can remove whatever fortune you want to remove.
### Basic Functionality: If one opens the window, there are 12 articles prepared for the default setting.
